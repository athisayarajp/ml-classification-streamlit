# ML Assignment 2 – Bank Marketing Classification 

Classification of whether a bank client subscribes to a term deposit, using five ML models and a Streamlit app.

## Dataset record details

Source:  UCI Machine Learning Repository – https://archive.ics.uci.edu/dataset/222/bank+marketing 
Name : Bank Marketing (`bank-additional-full.csv`)
Description : *A Data-Driven Approach to Predict the Success of Bank Telemarketing.* Decision Support Systems, 2014. 
Instance Size:  41,188 
Feature/ Predictors: 20 (10 numeric, 10 categorical) 
Target: `y` – client subscribed to a term deposit (`yes` / `no`)
